## Description

**requests-html** is a Python package designed to simplify the process of parsing HTML content, particularly for web scraping tasks. Unlike traditional HTML parsers that rely on static, pre-rendered content, `requests-html` leverages **Pyppeteer** to render web pages dynamically, enabling it to handle JavaScript-generated content effectively.

This makes it ideal for scraping modern websites that load content via JavaScript, such as social media platforms, e-commerce sites, or interactive dashboards. By rendering pages in a real browser environment, `requests-html` ensures that all content—including dynamically loaded elements—is available for parsing.

The library provides a clean, intuitive API that mirrors the familiar `requests` library, making it accessible even to users new to web scraping.

---

## Features

- ✅ **Dynamic HTML Rendering**: Uses Pyppeteer to render web pages in a real browser environment, supporting JavaScript-heavy websites.
- ✅ **Intuitive API**: Designed with a familiar syntax similar to `requests`, making it easy to adopt for existing Python developers.
- ✅ **Support for JavaScript-Generated Content**: Handles content loaded via AJAX or dynamically generated by JavaScript.
- ✅ **Flexible Parsing Options**: Offers multiple parsing methods (e.g., `find()`, `xpath()`, `search()`) with support for clean HTML and text extraction.
- ✅ **Built-in User-Agent Rotation**: Automatically rotates user agents to avoid detection by anti-bot measures.
- ✅ **Session Management**: Supports session-based requests with cookies, headers, and authentication.
- ✅ **Async Support**: Includes an asynchronous version (`AsyncHTMLSession`) for high-performance scraping with concurrency.
- ✅ **Content Navigation**: Allows navigation through paginated content using `next()` and `links()` methods.
- ✅ **Error Handling and Retries**: Configurable retry logic for failed requests or timeouts.

## Usage

### Basic Usage

```python
from requests_html import HTMLSession

# Create a session
session = HTMLSession()

# Render a page with JavaScript
r = session.get('https://example.com')

# Parse the HTML content
html = r.html
print(html.title.text)
print(html.find('h1', first=True).text)
```

### Asynchronous Usage

For faster scraping with concurrency:

```python
from requests_html import AsyncHTMLSession

async def scrape_page():
    async_session = AsyncHTMLSession()
    try:
        r = await async_session.get('https://example.com')
        print(r.html.title.text)
    finally:
        await async_session.close()

# Run the async function
import asyncio
asyncio.run(scrape_page())
```

### Handling Dynamic Content

```python
from requests_html import HTMLSession

session = HTMLSession()

# Render a page with a custom script
r = session.get('https://example.com', script='console.log("Loaded!");')

# Extract dynamic content
print(r.html.find('div.content', first=True).text)
```

### Navigating Pages

```python
from requests_html import HTMLSession

session = HTMLSession()

r = session.get('https://example.com')

# Get the next page link
next_page = r.html.links()

# Iterate through pages
for page in r.html:
    print(page.url)
```
